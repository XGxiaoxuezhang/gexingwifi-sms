连接短信设备

浏览器直连串口，短信数据不经过任何服务器

1用数据线连接随身WiFi，确认它出现在 设备管理器 → 端口
2选择波特率（一般 115200），点「连接设备」
3在浏览器弹窗中选择该设备的 AT 端口
需使用 Chrome / Edge 等 Chromium 内核浏览器，并通过 https 或 localhost 打开本页 （浏览器安全限制，直接双击 html 文件无法访问串口）。
串口同一时间只能被一个程序占用，连接前请先关闭其他占用该串口的程序。
