连接随身WiFi / 短信设备

  1. 用数据线把设备连到电脑，确认它出现在「设备管理器 → 端口」里
  2. 点下面的「连接设备」，在浏览器弹出的窗口中选择该串口
  3. 连接后即可收短信、发短信、调试 AT 指令
必须使用 Chrome / Edge 等 Chromium 内核浏览器，并通过 https 或 localhost 打开本页 （Web Serial 的安全限制，直接双击 html 文件无法使用）。
串口只能被一个程序占用，连接前请先关闭其他占用该串口的程序（含本项目的托盘监控）。
