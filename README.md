# 随身WiFi 短信助手

把 ASR 随身WiFi（或任何支持标准 AT 指令的短信猫 / 4G 模块）变成一台「短信中心」：
在电脑上实时收短信、来短信自动提醒、用网页收发短信，还能把网页开到手机上用。

全流程 Windows 原生，**不需要安装 Python、Node 等任何运行时**。

---

## 功能

- **读短信**：串口读取 SIM 卡全部短信，自动解码中文（UCS2）
- **来短信提醒**：网页语音播报「您有新的短信，请注意查收」+ 托盘气泡提示 + 标签页新短信计数
- **网页界面**：深浅色聊天式界面，列表 / 详情 / 回复
- **实时推送**：网页使用 SSE 推送，来短信立即显示（不支持时自动降级为 2 秒轮询）
- **发送短信**：网页直接回复，支持超长短信自动分条（UCS2 单条 70 字）
- **删除短信**：从网页删除，同步删除 SIM 卡上的记录
- **联系人备注**：给号码起名字，列表和详情显示备注
- **未读管理**：打开即已读、一键全部已读，托盘显示未读数
- **托盘常驻**：后台运行，子进程崩溃自动重启，新短信气泡提醒
- **开机自启**：托盘菜单一键开关
- **局域网访问**：可选开放给手机浏览器，支持访问令牌保护
- **端口自动探测**：串口号变了也能自动找到设备

---

## 快速开始

1. 用数据线把随身WiFi 连到电脑，确认它出现在「设备管理器 → 端口(COM 和 LPT)」里
2. 如果端口不是 `COM12`，打开 `config.json` 把 `port` 改成实际端口（不确定就保持 `auto_detect_port: true`）
3. 双击 **`短信网页监控.bat`**

程序会在托盘常驻，并自动打开浏览器进入 <http://127.0.0.1:8666> 。

托盘图标右键可切换「开机自动启动」、打开程序目录、退出监控；双击图标可重新打开网页。

## 目录结构

```
wifi-sms/
├─ 短信网页监控.bat        # 唯一入口：托盘 + 网页 + 轮询
├─ config.json             # 全局配置（端口、网页端口、令牌等）
├─ sms_tray.ps1            # 托盘程序：拉起子进程、监管、气泡提醒、开机自启
├─ sms_web_poll.ps1        # 轮询服务：读短信 + 发送队列 + 删除队列 + 已读同步
├─ sms_web_server.ps1      # 网页服务器（零依赖，PowerShell 实现，默认使用）
├─ sms_common.ps1          # 公共模块：配置、串口、AT 指令、UCS2、日志
├─ logs/                   # 运行日志（自动创建，超 1MB 转存 .old）
└─ sms_web/
   ├─ index.html           # 网页界面
   ├─ server.py            # 网页服务器（Python 版，可选）
   ├─ data.json            # 短信数据（轮询服务写入，网页读取）
   ├─ send_queue.json      # 待发送队列
   ├─ delete_queue.json    # 待删除队列
   ├─ read_marks.json      # 待同步的已读标记
   ├─ contacts.json        # 联系人备注
   └─ send_result.json     # 发送结果 {id: {status,message,ts}}
```

## 配置说明（config.json）

```json
{
  "port": "COM12",
  "baud": 115200,
  "poll_sec": 8,
  "auto_detect_port": true,
  "web_host": "127.0.0.1",
  "web_port": 8666,
  "server_engine": "auto",
  "access_token": ""
}
```

| 字段 | 说明 |
| --- | --- |
| `port` | 串口名，如 `COM12`。改完保存即可，无需改任何脚本 |
| `baud` | 波特率，一般是 `115200`；老设备可能是 `9600` |
| `poll_sec` | 轮询间隔（秒）。越小越及时，越费资源，建议 5~10 |
| `auto_detect_port` | `true` 时，若 `port` 打不开会自动扫描所有串口找设备 |
| `web_host` | `127.0.0.1` 仅本机；`0.0.0.0` 开放给局域网（见下文） |
| `web_port` | 网页端口，默认 `8666` |
| `server_engine` | `auto` / `powershell` / `python`，见「关于 Python」 |
| `access_token` | 访问令牌，非空时网页接口需要携带令牌 |

修改配置后重启程序生效（托盘右键 → 退出监控，然后重新双击 bat）。

## 网页界面

- **列表**：显示发件人（有备注则显示备注名 + 号码）、内容预览、时间，未读高亮
- **详情**：打开即标记已读，可复制全文、加/改备注、删除短信
- **回复**：Ctrl+Enter 或点「发送」；超过 70 字会自动拆成多条发送
- **右上角**：
  - `全部已读`：清空所有未读高亮
  - `语音：开/关`：新短信语音播报（点开时会试播一次；没有中文语音时自动退回「嘀嘀」提示音）
  - 徽标显示 `实时`（SSE 已连接）或 `轮询`（降级模式）
- 浏览器标签标题会在来新短信时显示 `(N条新短信)`

## 关于「没有 Python 的用户怎么办」

**默认就不需要 Python。**

网页服务器有两个等价实现，程序会自动选择：

| 引擎 | 文件 | 依赖 |
| --- | --- | --- |
| PowerShell（默认） | `sms_web_server.ps1` | **无**，用 Windows 自带的 PowerShell / .NET |
| Python（可选） | `sms_web/server.py` | 需要 Python 3.7+ |

`server_engine` 取值：

- `auto`（默认）：使用 PowerShell 引擎；只有当你在托盘启动后发现网页打不开、并且本机装了 Python 时，会自动降级到 Python 引擎再试一次
- `powershell`：强制使用内置引擎（零依赖）
- `python`：强制使用 Python 引擎（未装 Python 时会自动退回 PowerShell 并写日志）

两个引擎接口完全一致，网页功能和数据文件格式也完全相同，可以随时切换。

> 少数系统上 PowerShell 的 `HttpListener` 绑定 localhost 可能需要 URL ACL 权限。
> 此时把 `server_engine` 改成 `python` 即可（或参考「常见问题」手动授权）。

## 局域网访问（手机也能看短信）

1. 编辑 `config.json`：
   ```json
   "web_host": "0.0.0.0",
   "access_token": "换成一串你自己的密码"
   ```
2. 重启监控（托盘右键退出后重新双击 bat）
3. 手机连同一个 WiFi，浏览器打开 `http://电脑IP:8666/?token=你的令牌`

注意：

- **必须设置 `access_token`**，否则同一网络下的任何人都能看到你的短信（短信里常有验证码）
- 令牌只需输入一次，网页会存到浏览器本地
- 使用 PowerShell 引擎时，监听 `0.0.0.0` 需要**以管理员身份运行**（Windows 的 URL ACL 限制）；
  若不想用管理员权限，可把 `server_engine` 设为 `python`
- 首次开放时 Windows 防火墙可能弹窗，选择「允许专用网络」

## 开机自动启动

托盘图标右键 → 勾选 **开机自动启动**。

它会在注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入一项 `WiFiSmsMonitor`，
取消勾选即移除。不需要管理员权限。

## 日志与排错

日志在 `logs/` 目录：

| 文件 | 内容 |
| --- | --- |
| `poll.log` | 串口连接、新短信、发送 / 删除结果、异常 |
| `web.log` | 网页服务器启动、监听失败原因 |
| `tray.log` | 托盘启动、子进程崩溃与重启、自启设置 |

每个文件超过 1MB 会自动转存为 `.old`。

**常见问题**

| 现象 | 处理 |
| --- | --- |
| 网页打不开 | 看 `logs/web.log` 最后几行；若提示监听失败，把 `server_engine` 改成 `python`（需装 Python），或以管理员身份运行 |
| 收不到新短信 | 确认 `config.json` 的 `port` 正确、串口没被其他程序（如串口助手）占用；看 `logs/poll.log` |
| 短信是乱码 | 确认 `baud = 115200`；若设备是 9600 请改小 |
| 中文短信显示成十六进制 | 已内置 UCS2 解码；若仍异常请把原始内容贴到 issue |
| 发送失败 | 看 `logs/poll.log` 的「发送结果」；余额不足、号码格式错误都会返回 ERROR |
| 托盘图标不见了 | 在隐藏图标里找；若进程已退出，重新双击 `短信网页监控.bat` |
| 来短信没有语音 | 系统缺中文语音包：Windows「设置 → 时间和语言 → 语言和区域」为中文添加「语音」组件；没有中文语音时会自动退回「嘀嘀」提示音 |
| 想改播报内容 | 编辑 `sms_web/index.html` 顶部的 `NEW_SMS_TEXT` 常量（默认「您有新的短信，请注意查收」） |
| 忘记访问令牌 | 查看 `config.json` 的 `access_token` |

**手动授权 URL ACL**（仅在需要以普通权限监听局域网时用，需管理员执行一次）：

```powershell
netsh http add urlacl url=http://+:8666/ user=%USERNAME%
```

## 工作原理

脚本通过串口向模块发送标准 AT 指令：

| 指令 | 作用 |
| --- | --- |
| `AT` | 连通性探测（自动找端口时用） |
| `AT+CMGF=1` | 文本模式 |
| `AT+CSCS="GSM"` / `"UCS2"` | 字符集，中文短信收发走 UCS2 |
| `AT+CMGL="REC UNREAD"` | 取未读短信 |
| `AT+CMGL="ALL"` | 取全部短信 |
| `AT+CMGS="<UCS2号码>"` | 发送短信，正文以 UCS2 + `Ctrl+Z(0x1A)` 结束 |
| `AT+CMGD=<index>` | 删除指定短信 |

数据流：

```
串口 ──> sms_web_poll.ps1 ──> sms_web/data.json ──> 网页（SSE 实时推送）
                    ▲                                      │
                    └──── send_queue.json ◄─── 网页点「发送」─┘
                    └──── delete_queue.json ◄─ 网页点「删除」─┘
                    └──── read_marks.json ◄─── 打开短信即已读 ─┘
```
