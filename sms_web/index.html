调试须知
· 进入本页会自动暂停短信监控（把串口让给浏览器），切回「短信」标签或关闭页面即自动恢复。
· 「删除 / 写入」IMEI、SN、WiFi ID 需先开启工厂模式，且要先「删除」再「写入」；写错可能导致设备无法上网。
· 「锁定频段」「重启」会中断当前网络，请确认后再操作。
· 需要 Chrome / Edge 等 Chromium 内核浏览器，并通过 127.0.0.1 或 HTTPS 访问本页。
